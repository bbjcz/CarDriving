## 游戏操作

#### 键盘按键功能

| 按键 | 功能 |
| --- | --- |
| Esc | 暂停游戏，调出暂停菜单 |
| W | 加速 |
| S | 制动 |
| A | 向左打方向 |
| D | 向右打方向 |
| Q | 切换前进/倒车模式（只能在车静止时切换） |

#### 鼠标功能

移动视角
